## 보여드릴 것

**① 화면 시연** — 세 가지 상태

1. 정상 — dummyjson에서 받아온 상품 목록
2. Slow 4G로 새로고침 → 로딩 표시
3. URL 오타 → 에러 화면 (페이지가 죽지 않음)

**② `main.js`** — 3단 구조

1. `createProductCard` — 상품 객체를 받아 카드 HTML 문자열을 돌려준다
2. `loadProducts` — API를 호출하고 응답을 두 번 벗긴 뒤 상품 배열을 반환한다. `response.ok`가 아니면 `throw`
3. `render` — 로딩 표시 → 배열을 `map`으로 카드 HTML로 바꾸고 `join`으로 합쳐 삽입. `try`/`catch`로 에러 화면 처리

**③ `docs/NOTES.md`** — 특히 1-12 참조/값 부분 (지난 회차 숙제)
