### 보여드릴 것

**① 화면 시연** — 담기 버튼을 누르면 헤더 숫자가 올라간다

**② `main.js` 클릭 핸들러** — 이벤트 위임

```js
productList.addEventListener("click", (event) => {
    const clicked = event.target;

    if (clicked.classList.contains("product-card__add")) {
        const productId = Number(clicked.dataset.id);
        const product = products.find((p) => p.id === productId);
        cart.push(product);
        updateCartCount();
    }
});
```

버튼마다 리스너를 달지 않고 **부모에 하나만** 달았다. 버튼이 `fetch` 이후에 생기고, `innerHTML`로 목록을 다시 그리면 리스너가 사라지기 때문이다.

**③ `docs/NOTES.md`** — M2-1 ~ M2-6 정리

### 이번에 걸렸던 것

**`dataset`으로 꺼낸 값은 항상 문자열이다.** HTML 속성값에는 타입이 없기 때문이다. 그냥 두면 `find`가 **에러 없이** `undefined`를 돌려준다. 꺼내는 자리에서 `Number()`로 변환했다.

**`cart.push(product)`는 복사가 아니라 주소를 한 번 더 적는 것이다.** 확인해보니 `cart[0] === products에서 찾은 상품`이 `true`였다. M2-7에서 수량을 더할 때 원본 상품 목록까지 오염되므로, 전개 구문으로 분리된 객체를 넣을 예정이다.
