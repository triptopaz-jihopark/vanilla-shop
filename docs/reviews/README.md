## 작성 규칙

- 회차마다 `YYYY-MM-DD.md` 파일 하나. 한 파일에 누적하지 않는다
- 질문은 `###` 헤딩으로 — 에디터 아웃라인에서 바로 점프할 수 있다
- 답변은 질문 **바로 아래** 둔다
- 긴 부연 설명은 `<details>`로 접는다 — 함께 화면을 보며 이야기할 때 스크롤이 줄어든다
- 상태 표시: ✅ 답변 완료 / 🔄 후속 확인 필요 / ⬜ 미답변
- 새 회차는 `_TEMPLATE.md`를 복사해서 시작한다
- 시간이 모자라면 질문을 **다음 회차로 미룬다.** 미룬 질문은 "다음 회차로 미룬 질문" 항목에 남겨 잊지 않도록 한다

## 함께 볼 때

- VS Code 미리보기 `Cmd+Shift+V` (나란히 보기는 `Cmd+K` → `V`)
- 질문 사이 이동은 `Cmd+Shift+O`
- 또는 GitHub에 push 후 브라우저로 — 링크를 미리 공유하면 각자 화면에서 볼 수 있다
